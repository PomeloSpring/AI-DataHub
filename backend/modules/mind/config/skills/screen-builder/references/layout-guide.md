# 大屏布局与栅格

工具侧画布基准 **1920 × 1080**。`create_data_screen` 未给 `position` 时按下列规则自动布局
（2026-11-17 整改：同屏多站 + 观感收敛）：

| 场景 | 自动布局规则 |
|------|--------------|
| **多站一屏**（widget 出现 ≥2 个不同 `site`） | **站点矩阵**：列 = 站点（列宽 = 1920/站点数），行 = 指标家族（KPI / 趋势 / 其他）；同族等高、同站同列，缺格留空不拉伸。站点顺序 = 用户给出的顺序；异构卡（饼图/表格等「其他」族）未铺满全部站点时整行均分并居中 |
| 单站/无站，只有 1 张内容图 | KPI 行（单卡最宽 480，左对齐）+ 内容图满宽 |
| 单站/无站，2 张内容图 | KPI 行 + 左 2/3 趋势 / 右 1/3 占比（两张同族时对半） |
| 单站/无站，≥3 张内容图 | KPI 行 + 2~3 列网格，末行不足自动加宽铺满 |

要点：

- **KPI 单卡宽度上限 480**：一张 KPI 拉满整屏会让迷你趋势被拉平、大数字悬在中间（历史观感缺陷）。
- **同族同排**：趋势族不跟饼图/表格/地图混行；混行会让观众以为是同一量级对比。
- **异构卡不进对比矩阵**：状态构成/表格/地图只在部分站点有时，不按站点列摆（会留出右侧一大片空白），改用整行均分居中（单张最宽 2/3 屏）；只有每站都有的同族图才是对比项。
- 未写 `site` 的图（跨站屏里漏标）落到**底部整行**，不静默丢图；建后核对 `layout` 看是否落到了底行。
- 总图数上限 **24**；5 站 × 3 指标 = 15 是常见规模，超过 24 才拆板。

## 两套版面几何(易错点,务必区分)

同一个看板对象有两套版面口径,`position` 只驱动其中一套:

| 视图 | 几何 | 谁写 |
|------|------|------|
| 大屏播放 `/screen/<id>` | 走 `ResponsiveDashboardCanvas` → **响应式列格** | 由 `position` 像素**等比换算**得出(`automatic` 项),按断点重排 |
| 看板页面/编辑器 | pageLayout v3:desktop **48 列** × 行单位 **4px** | 前端编辑器「页面布局」保存,本工具无入口 |

推论(均为实测踩过的坑):

- `position` 的 `w/h` **只保证相对比例**,不保证像素级所见即所得;窄屏/平板会换列数重排,别向用户承诺像素还原。
- 控件类(`widget_*`)在页面视图按**自然尺寸**生成,不按 position 等比放大;图表才按等比映射。
- 列宽换算必须**把 gap 算进去**(只按列数等分不含间距会让控件/卡片窄一截,历史缺陷:日期区间控件"只显一半");行高单位是 4px,`gridAutoRows` 不再叠加行间距。
- 精确版面(网格列数、控件行、间距)只能在编辑器保存页面布局;AI 侧生成后如需微调,引导用户进编辑器,或改 `position` 比例后重生成。

## 常见版式

- **多站对比一屏**（首选，用户要「一个屏看所有站」时）:列 = 站点、行 = 指标。每站一列：顶部 KPI（今年累计/同比）→ 中部趋势（月度走势）→ 底部构成（状态/类型占比）。5 站 = 5 列，每列 384px 宽；图数 5×3=15。
- **经营驾驶舱**:顶部 4 个 KPI 卡(y=0,h=180)→ 中部主趋势图占左 2/3 + 右侧占比/排行 → 底部明细表或多维雷达。用 `layout_kpi_top`。
- **实时监控**:九宫格 `layout_grid_3x3`,每格一个 gauge/迷你趋势。
- **焦点分析**:左主右辅 `layout_left_right`,左侧大趋势/地图,右侧排行/KPI 列表。

> 不要为「每站一块板」而分身：除非用户明确要求分屏，多站永远先按上面的「多站对比一屏」排。

## 建后版面自检（对着 `layout` 逐条看）

1. KPI 是否在同一行、有没有被拉成整屏宽；
2. 站点列有没有串列（每列应是同一站点，列宽相等）；
3. 同族图是否同排（趋势不跟饼图混行）；
4. 只有部分站点才有的异构卡是否挡住了整行（应居中而非靠左留出右侧空白）；
5. 卡片之间留白 ≥12px、无重叠；
6. 图数 ≤24，超了就拆板并告知用户为什么拆。

## 信息层级

- 最重要指标放左上与顶部;观众视线从左上看起。
- 同类图放同一行/列;留白 ≥ 12px;避免同一屏混用超过 2 种图表家族。
- 标题栏 `frame_title_bar` 放整屏标题与时间;角标框 `frame_tech_corner` 强化科技感。

## 图表选型(与渲染器一致)

趋势→`line/area/timeseries_line`;对比→`bar`;占比→`pie/rose/treemap`;多维→`radar`;转化→`funnel`;达成→`gauge`;排行/明细→`table/table_value`;核心数字→`big_number_trend/text_display`;地理→`china_map/world_map`。
