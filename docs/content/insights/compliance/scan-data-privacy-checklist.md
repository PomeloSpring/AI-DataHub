## 一、先纠正一个认知：口扫数据是个人信息

常见误解是"我只扫了牙齿表面，没有姓名，所以不是个人信息"。这个判断是错的。

- 《个人信息保护法》第 28 条把**医疗健康信息**列为敏感个人信息；第 29 条要求处理敏感个人信息应当取得个人的**单独同意**。
- GB/T 39725-2020 对"个人健康医疗数据"的界定是"**单独或者与其他信息结合后能够识别特定自然人**"。口扫文件通常伴随就诊号、牙位信息、拍摄时间，且三维形态本身具有个体区分度——它与就诊记录结合即可识别到人。
- 《民法典》第 1226 条明确：医疗机构及其医务人员泄露患者隐私和个人信息，或未经患者同意公开其病历资料的，应当承担侵权责任。

**结论**：口扫数据的处理规则应按敏感个人信息来定，而不是按"工程文件"来定。

## 二、四个高危场景与处置

### 场景 1：把病例发给外部沟通工具"看一下"

这是最常见也最严重的一类。哪怕只发一个 STL，只要能与就诊信息关联，就构成未经同意的对外提供。

处置：
- 建立**受控外发通道**（企业内批准的协作平台），并在流程上留痕；
- 外部协作确有必要时，走**去标识化**处理：移除文件内嵌的患者标识字段、重命名文件、不随附就诊信息；
- 与外部方签数据使用协议，明确使用目的、范围与安全责任。

### 场景 2：设备维修/售后演示使用真实病例

工程师培训、故障复现、方案演示都容易顺手拿真实数据。

处置：
- **默认禁止**。故障复现优先用标准件或合成数据；
- 确实需要真实数据复现的，须取得相应授权、限定在受控环境、事后删除并留记录；
- 演示材料一律使用脱敏或合成数据，并在页面上标注数据来源。

### 场景 3：云端备份与远程会诊

数据出了机构边界，责任划分最容易含糊。

处置：
- 与云服务方明确**留存期限与到期删除责任**，写进合同而不是口头约定；
- 传输与存储加密，访问按角色最小授权，开启多因素认证；
- 远程会诊需患者知情与单独同意，并记录参与方；
- 参照 GB/T 39725-2020 的分级要求配置差异化措施（可完全公开级 / 限制级 / 隐私级 / 关键级），不得对所有数据用同一套弱控制。

### 场景 4：把数据用于产品研发或算法训练

这是厂商与机构之间最容易"默认同意"的地带。

处置：
- 需要**单独同意**或合法依据，不能靠隐私政策里一句话概括授权；
- 优先做**去标识化/匿名化**：匿名化后应达到无法识别特定自然人且不能复原；
- 训练数据集登记来源、授权范围与使用边界，形成可审计的数据台账；
- 数据二次利用建议参照 GB/T 39725-2020 的"临床研究/二次利用"场景条款走审批流程。

## 三、可直接落地的自查表

| 项 | 要求 | 证据 |
|---|---|---|
| 知情与同意 | 采集前告知目的、方式、范围；敏感处理取得单独同意 | 同意记录/表单版本 |
| 访问控制 | 按角色最小授权，关键岗位权限复核 | 权限清单与变更记录 |
| 传输加密 | 院内与跨网传输均加密 | 配置证明 |
| 存储加密与分级 | 按数据级别选择加密强度与存放位置 | 数据台账 |
| 外发管控 | 只走受控通道，留痕可查 | 审计日志 |
| 日志留存 | 访问与外发日志留存不少于 1 年 | 日志系统配置 |
| 留存期限 | 约定期限与到期删除责任 | 合同条款 |
| 应急预案 | 制定网络安全事件应急预案并按规定报告 | 预案文本与演练记录 |
| 风险评估 | 定期开展数据安全风险评估 | 评估报告 |
| 培训 | 全员个人信息保护与数据合规培训 | 培训记录 |

## 四、给设备厂商的额外一条

作为设备与软件提供方，你们还会接触机构的运维数据。请注意：

- **设备遥测里不要携带可识别到患者的信息**（文件名、病例号、影像缩略图都不该出现在遥测里）；
- 网络安全能力要能对上注册口径：数据接口、用户访问控制等是产品技术要求里的实际项（见 `regulatory-standards-map`）；
- 若提供云端数据服务，责任边界（谁是数据控制者、谁是处理者）要在合同里写清。

本公司的遥测字段清单与脱敏规则由产品与平台团队维护，属内部受控文件，本文不代列具体字段。

## 五、发布到公开栏目时的脱敏要求（与本模块直接相关）

把病例做成公开内容（如临床应用复盘、数据洞察）时，必须同时满足：

1. 不含姓名、就诊号、联系方式、可识别的日期与地点组合；
2. 不含可复原的三维模型文件；截图需去除界面中的患者信息区域；
3. 影像/模型若展示，须为合成数据或已获明确授权并标注；
4. 统计类内容只呈现聚合结果，样本量过小的分组（如某单机构 < 10 例）不予发布——小组数据即使去掉姓名也可能重识别。

本栏目所有内容在发布前须经**法规与质量部复核**，复核结论留档。
