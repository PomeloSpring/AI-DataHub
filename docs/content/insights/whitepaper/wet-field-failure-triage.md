## 一、为什么"处置顺序"比"手法"更重要

三类失败会同时出现，但它们的**处置有严格的先后依赖**：

```
控湿 → 控血 → 控反光 → 再谈补扫路径
```

顺序颠倒的后果是**把误差固化**：在还有水膜的情况下补扫，算法会把散射出来的假点云当成真实几何接受下来，模型看起来"完整"，实际是错的。这类失败最危险的地方在于**它不报错**。

一条判断原则：**任何"看起来已经扫全了"的结果，如果采集时表面状态不达标，都不算完成。**

## 二、三类根因的识别特征

| 根因 | 视觉/系统特征 | 常见牙位 | 典型误判 |
|---|---|---|---|
| **水膜（唾液/龈沟液）** | 局部出现"雾状"或高反光的连续面，边缘发虚但不断开 | 下后牙舌侧、上颌腭侧 | 以为扫全了 |
| **渗血** | 肩台线局部断裂，缺口边界清晰且随时间扩大 | 有排龈需求的前磨牙/磨牙预备体 | 以为是软组织遮挡，让患者张嘴就完事 |
| **反光（金属/釉质高光）** | 出现空洞或跳点，同一区域反复采集仍无法补全 | 大面积金属修复体、深色或高抛釉质 | 以为是路径不够，反复扫导致过采样 |

区分水膜与反光有一个可操作的办法：**改变表面状态后再扫一小块**。水膜靠隔湿与擦拭会立刻变化；金属反光不会因擦拭改变，需要靠曝光策略或喷粉处理。

## 三、分场景处置流程

### 3.1 水膜

1. **先物理隔湿，再考虑吸引**：棉卷 + 吸唾器是基线；单纯靠吸引器"边吸边扫"在舌侧窝位几乎无效。
2. **分区隔离**：一次只暴露一个象限，其余用棉卷与唇颊牵开器挡住。暴露时间越长，二次污染概率越高。
3. **缩短单区时长**：单区控制在 60—90 秒内完成，超时先退出重来，不要在已污染的区上继续叠。
4. **不要在喷水降温的同时扫描**：水雾会直接落到目标面上。

### 3.2 渗血

1. **排龈是首选，不是压迫止血**。排龈线放置后需要等待（时间按所用材料说明），提前开始扫描等于白扫。
2. **持续负压优于间断吸引**：间断吸引会把血凝块从龈沟带走，造成持续渗出。
3. **两次隔湿仍失败就要退回传统印模**，不要硬扫。龈下边缘较深（> 1.5 mm）且反复失败时，强行补扫产出的模型会直接导致修复体边缘不密合，后续表现为牙龈炎症与牙周袋加深——这是比返工更贵的代价。

### 3.3 反光

1. **优先调采集策略**（曝光/多帧融合），再考虑喷粉。喷粉会引入颗粒厚度，影响边缘精度，属于"有代价的手段"，用了要在加工单上注明。
2. **大面积金属修复体**：这类区域在文献里被反复证实是精度短板，不要期待算法能补出来。必要时改用分区扫描 + 个别托盘辅助。
3. **深色牙龈与高抛釉质**同属低对比度场景，容易丢失配准特征，需要放慢移动速度、增加重叠。

## 四、环境光是变量，不是背景

Arakida 等（2018）的研究把**环境光**列为影响 trueness、precision 与扫描时间的独立变量。落到诊室里有三条可执行动作：

- 强自然光直射的诊室，拉窗帘或用遮光屏；椅旁灯不要直接照在目标牙面上。
- 同一诊室做设备精度复测时，**光照条件必须一致**，否则两次结果不可比（见 `clinic-accuracy-self-check`）。
- 助手手机屏幕、显示器反光也算环境光，别忽略。

## 五、扫描路径：把它当可测量变量

Jeon & Choi（2020）的体外研究比较了不同扫描策略得到的全牙弓精度差异，结论支持一个实践主张：**路径顺序应作为标准作业书写死，而不是每位医生的个人习惯**。

建议的最小规范：

1. 起点固定（如下颌左侧第二磨牙远中）。
2. 方向固定（先舌/腭侧后唇颊侧，因为舌腭侧受软组织干扰更大，先拿到稳定基准）。
3. 重叠率固定（相邻视野保留足够重叠，避免"跳着扫"）。
4. 咬合记录在上下颌单弓完成之后、患者疲劳之前做。

## 六、把失败记下来，才能把它消掉

现场处置只能救单个病例，**归因统计才能减少下一批病例**。建议每次中断记录三个字段：

| 字段 | 取值 | 用途 |
|---|---|---|
| 根因 | 水膜 / 渗血 / 反光 / 软组织 / 患者移动 / 路径不足 / 未知 | 决定改进方向 |
| 牙位与象限 | 标准牙位记录 | 定位视野与器械可达性问题 |
| 补扫次数 | 整数 | 与总时长、返工率做相关性分析 |

本公司近 12 个月的中断原因分布由售后与临床数据组按上表根因口径统计，属内部受控数据，本文不代列。在拿到这份统计之前，本文的处置优先级属于经验排序，请勿当作本公司数据得出的结论。
