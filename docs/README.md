# docs/ 目录说明

本目录用于存放 **项目官方文档**，与AI执行计划（.claude/）分开管理。

## 📁 目录结构

```
docs/
├── api/                # API文档
├── user-guide/         # 用户指南
├── deployment/         # 部署文档
├── development/        # 开发文档
└── README.md           # 本说明文件
```

## 📋 文档类型说明

### api/ - API文档

存放项目的：
- REST API接口文档
- WebSocket接口文档
- 数据模型文档
- 错误码说明

### user-guide/ - 用户指南

存放项目的：
- 用户使用手册
- 功能说明
- 操作指南
- 常见问题

### deployment/ - 部署文档

存放项目的：
- 环境要求
- 安装步骤
- 配置说明
- 运维指南

### development/ - 开发文档

存放项目的：
- 开发环境搭建
- 代码规范
- 贡献指南
- 架构说明

## 🔗 与 .claude/ 的区别

| 目录 | 内容 | 维护者 | 用途 |
|------|------|--------|------|
| `.claude/` | AI执行计划 | AI Claude Code | 指导代码实现 |
| `docs/` | 项目文档 | 开发团队 | 用户文档、API文档 |

## 📝 使用规范

1. **项目官方文档** → 放在 `docs/`
2. **AI生成的文档** → 放在 `.claude/`
3. **保持分离**：不要混放两种类型的文档
4. **及时更新**：代码变更时同步更新文档
