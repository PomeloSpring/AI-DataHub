# 数据源配置指南

## 概述

数据源是AI-DataHub连接外部数据库的配置。系统支持多种数据库类型。

## 支持的数据库类型

| 数据库 | 说明 | 用途 |
|--------|------|------|
| MySQL | 关系型数据库 | 业务数据存储 |
| Apache Doris | 分析型数据库 | 向量存储、分析查询 |
| Elasticsearch | 搜索引擎 | 日志分析 |
| PostgreSQL | 关系型数据库 | 业务数据存储 |

## 创建数据源

### 步骤1：进入数据源管理页面

- 路径：系统配置 → 数据配置 → 数据源管理
- URL：`/system/datasources`

### 步骤2：点击"新建数据源"按钮

### 步骤3：填写数据源信息

#### 基本信息

| 字段 | 说明 | 必填 | 示例 |
|------|------|------|------|
| 数据源名称 | 显示名称 | 是 | MySQL-生产库 |
| 数据库类型 | 数据库类型 | 是 | MySQL |
| 描述 | 数据源描述 | 否 | 生产环境主数据库 |

#### 连接配置

| 字段 | 说明 | 必填 | 示例 |
|------|------|------|------|
| 主机地址 | 数据库服务器地址 | 是 | 192.168.1.100 |
| 端口 | 数据库端口 | 是 | 3306 |
| 数据库名 | 数据库名称 | 是 | mydb |
| 用户名 | 数据库用户名 | 是 | readonly |
| 密码 | 数据库密码 | 是 | ******** |

#### 高级配置

| 字段 | 说明 | 默认值 |
|------|------|--------|
| 连接超时 | 连接超时时间（秒） | 10 |
| 查询超时 | 查询超时时间（秒） | 60 |
| 最大连接数 | 连接池最大连接数 | 10 |
| SSL连接 | 是否使用SSL | 否 |

### 步骤4：测试连接

点击"测试连接"按钮，验证配置是否正确。

### 步骤5：保存数据源

点击"保存"按钮创建数据源。

## 数据源管理

### 查看数据源列表

数据源列表显示所有已配置的数据源，包括：
- 数据源名称
- 数据库类型
- 主机地址
- 连接状态

### 编辑数据源

点击数据源名称或"编辑"按钮，可以修改数据源配置。

### 测试连接

点击"测试连接"按钮，验证数据源连接是否正常。

### 删除数据源

点击"删除"按钮，可以删除数据源。注意：删除数据源会影响相关的定时任务和Agent配置。

## 数据源同步

### 同步表元数据

1. 进入：系统配置 → 数据配置 → 表元数据
2. 选择数据源
3. 点击"同步"按钮

系统会自动读取数据库的表结构、字段信息等元数据。

### 同步业务术语

1. 进入：系统配置 → 数据配置 → 业务术语
2. 手动添加或导入业务术语
3. 关联到对应的表和字段

## 最佳实践

1. **使用只读账号**：建议使用只读权限的数据库账号
2. **连接池配置**：根据并发量调整最大连接数
3. **超时设置**：根据网络环境设置合理的超时时间
4. **定期测试**：定期测试数据源连接是否正常
5. **安全保护**：密码等敏感信息会加密存储

## 常见问题

### Q: 连接测试失败怎么办？

A: 检查以下几点：
1. 主机地址和端口是否正确
2. 数据库用户是否有访问权限
3. 防火墙是否允许连接
4. 数据库服务是否正常运行

### Q: 如何修改数据源密码？

A: 编辑数据源，修改密码字段，然后测试连接验证。

### Q: 数据源删除后还能恢复吗？

A: 不能恢复，删除前请确认没有相关的定时任务和Agent配置。
