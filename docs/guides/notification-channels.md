# 通知渠道配置指南

## 概述

通知渠道用于接收定时任务执行结果、系统告警等消息。支持多种通知方式。

## 支持的通知渠道

| 渠道 | 说明 | 适用场景 |
|------|------|----------|
| 钉钉 | 钉钉群机器人 | 团队协作 |
| 飞书 | 飞书群机器人 | 团队协作 |
| 企业微信 | 企业微信群机器人 | 企业内部 |
| 邮件 | SMTP邮件 | 正式通知 |
| Webhook | 自定义HTTP请求 | 系统集成 |

## 配置钉钉通知

### 步骤1：创建钉钉群机器人

1. 打开钉钉群设置
2. 选择"智能群助手"
3. 添加"自定义"机器人
4. 获取Webhook URL

### 步骤2：在系统中配置

1. 进入：系统配置 → 自动化 → 通知渠道
2. 点击"新建渠道"
3. 填写配置：
   - 渠道名称：如"研发群钉钉"
   - 渠道类型：钉钉
   - Webhook URL：粘贴钉钉机器人的Webhook URL
   - 安全设置：如果设置了加签，填写密钥

### 步骤3：测试通知

点击"测试"按钮，验证配置是否正确。

## 配置邮件通知

### 步骤1：获取SMTP配置

需要准备以下信息：
- SMTP服务器地址
- SMTP端口（通常为465或587）
- 发件人邮箱
- 邮箱密码或授权码

### 步骤2：在系统中配置

1. 进入：系统配置 → 自动化 → 通知渠道
2. 点击"新建渠道"
3. 填写配置：
   - 渠道名称：如"管理员邮件"
   - 渠道类型：邮件
   - SMTP服务器：如smtp.qq.com
   - SMTP端口：465
   - 发件人：your-email@qq.com
   - 密码：邮箱授权码
   - 收件人：receiver@example.com

## 配置Webhook通知

### 步骤1：准备接收端

确保有一个HTTP接口可以接收POST请求。

### 步骤2：在系统中配置

1. 进入：系统配置 → 自动化 → 通知渠道
2. 点击"新建渠道"
3. 填写配置：
   - 渠道名称：如"监控系统Webhook"
   - 渠道类型：Webhook
   - URL：接收端URL
   - 请求头：如 `{"Authorization": "Bearer xxx"}`

## 通知模板

系统支持自定义通知模板，使用变量插入动态内容。

### 可用变量

| 变量 | 说明 | 示例 |
|------|------|------|
| `{{task_name}}` | 任务名称 | 每日销售报表 |
| `{{status}}` | 执行状态 | 成功/失败 |
| `{{start_time}}` | 开始时间 | 2024-01-01 09:00:00 |
| `{{end_time}}` | 结束时间 | 2024-01-01 09:05:00 |
| `{{duration}}` | 执行时长 | 5分钟 |
| `{{result}}` | 执行结果 | 查询返回100条数据 |
| `{{error}}` | 错误信息 | SQL语法错误 |

### 模板示例

```
📊 定时任务执行通知

任务名称：{{task_name}}
执行状态：{{status}}
执行时间：{{start_time}} ~ {{end_time}}
执行时长：{{duration}}

{{#if result}}
📋 执行结果：
{{result}}
{{/if}}

{{#if error}}
❌ 错误信息：
{{error}}
{{/if}}
```

## 最佳实践

1. **分组管理**：按团队或业务创建不同的通知渠道
2. **测试验证**：配置后先测试通知是否正常
3. **备用渠道**：重要任务建议配置多个通知渠道
4. **权限控制**：Webhook URL等敏感信息注意保密
