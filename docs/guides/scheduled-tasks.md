# 定时任务配置指南

## 概述

定时任务功能允许用户设置自动执行的数据查询、分析和报告生成任务。系统支持多种执行模式和触发方式。

## 创建定时任务

### 步骤1：进入定时任务管理页面

- 路径：系统配置 → 自动化 → 定时任务
- URL：`/system/scheduled-tasks`

### 步骤2：点击"新建任务"按钮

点击页面右上角的"新建任务"按钮，打开任务编辑表单。

### 步骤3：填写任务基本信息

| 字段 | 说明 | 必填 | 示例 |
|------|------|------|------|
| 任务名称 | 任务的显示名称 | 是 | 每日销售报表 |
| 任务描述 | 任务的详细描述 | 否 | 每天早上9点生成前一天的销售报表 |
| 执行模式 | 任务的执行方式 | 是 | SQL模式 / Agent模式 |
| 数据源 | 执行查询的数据源 | 是 | MySQL-生产库 |

### 步骤4：配置执行内容

#### SQL模式

如果选择SQL模式，需要配置：
- **SQL查询**：要执行的SQL语句
- **查询参数**：可选的动态参数

示例SQL：
```sql
SELECT
    DATE(created_at) as 日期,
    COUNT(*) as 订单数,
    SUM(amount) as 总金额
FROM orders
WHERE DATE(created_at) = CURDATE() - INTERVAL 1 DAY
GROUP BY DATE(created_at)
```

#### Agent模式

如果选择Agent模式，需要配置：
- **Agent名称**：要使用的Agent
- **查询问题**：自然语言查询问题
- **最大迭代次数**：Agent最大迭代次数

示例问题：`统计昨天的销售数据，包括订单数和总金额`

### 步骤5：配置执行计划

| 字段 | 说明 | 必填 | 示例 |
|------|------|------|------|
| 执行周期 | 任务执行频率 | 是 | 每天 / 每小时 / 每周 |
| 执行时间 | 具体执行时间 | 是 | 09:00 |
| 时区 | 执行时区 | 否 | Asia/Shanghai |

常用Cron表达式：
- `0 9 * * *` - 每天早上9点
- `0 */2 * * *` - 每2小时
- `0 9 * * 1-5` - 工作日早上9点

### 步骤6：配置通知方式

选择任务执行结果的通知方式：

| 通知方式 | 说明 | 配置项 |
|----------|------|--------|
| 钉钉 | 发送到钉钉群 | Webhook URL |
| 飞书 | 发送到飞书群 | Webhook URL |
| 企业微信 | 发送到企业微信群 | Webhook URL |
| 邮件 | 发送邮件 | 收件人邮箱 |
| Webhook | 自定义Webhook | URL + 请求头 |

### 步骤7：保存任务

点击"保存"按钮创建任务。任务创建后可以在任务列表中查看和管理。

## 任务管理

### 查看任务列表

任务列表显示所有已创建的定时任务，包括：
- 任务名称
- 执行模式
- 执行周期
- 最后执行时间
- 执行状态

### 编辑任务

点击任务名称或"编辑"按钮，可以修改任务配置。

### 启用/禁用任务

点击任务状态开关，可以启用或禁用任务。

### 手动执行

点击"立即执行"按钮，可以手动触发任务执行。

### 查看执行日志

点击"执行日志"按钮，可以查看任务的历史执行记录。

## 最佳实践

1. **任务命名**：使用清晰的命名规范，如"每日_销售报表"
2. **执行时间**：避开业务高峰期
3. **超时设置**：根据查询复杂度设置合理的超时时间
4. **通知配置**：重要任务建议配置通知
5. **测试验证**：创建后先手动执行一次验证

## 常见问题

### Q: 任务执行失败怎么办？

A: 查看执行日志，检查：
1. SQL语法是否正确
2. 数据源连接是否正常
3. 查询是否超时

### Q: 如何修改任务执行时间？

A: 编辑任务，修改执行计划中的Cron表达式。

### Q: 任务结果如何导出？

A: 在执行日志中，点击"查看结果"，可以导出为CSV或Excel。
