Single-process FastAPI application (`main.py`) that mounts four domain routers under `/api/{quality,lineage,standards,security}` with Chinese tag groups. Each router file defines Pydantic request/response schemas and handler functions that persist to a relational database via shared helpers `services.shared.common.db` (`DBConnection`, `execute_query`, `execute_insert`, `execute_write`). Business logic is split by domain: `quality.py` manages rule CRUD, execution of individual/workspace-wide checks, result/report storage, and a dashboard aggregation; `lineage.py` stores nodes/edges in `adh_lineage_nodes`/`adh_lineage_edges` and provides upstream/downstream traversal plus a regex-based SQL parser; `standards.py` handles standard definitions and a placeholder compliance check; `security.py` tracks sensitive fields and auto-scans columns against keyword patterns. The service depends on cross-cutting DB utilities from `services/shared/common/db` and on the `quality_engine` module under `services.datagov.services` for rule execution, while Docker builds on `python:3.11-slim` and runs via uvicorn on port 8002.
