The module centers on `DashboardEditor.tsx`, which composes a left panel (`ComponentLibrary`), a center canvas, and a right panel (`PropertyPanel`) with an `EditorToolbar` at the top. The editor delegates canvas pan/zoom/drag/resize to the `useCanvasInteraction` hook and chart lifecycle (add/select/save/delete/template) to `useEditorCharts`; both hooks are consumed by the page component rather than encapsulated inside sub-components, keeping state centralized in the page. `DashboardChart` supplies the canonical `CHART_TYPES` / `CHART_TYPE_CATEGORIES` registry that both the library and property panel consume to render available chart/widget types. Rendering of each chart widget is done inline in the editor's canvas loop using absolute positioning driven by `position.x/y/w/h`, with a drop-preview overlay during drag-and-drop from the left panel. The reusable `components/ui/*` primitives (button, dialog, tabs, slider, select, tooltip, etc.) form a shared design system re-exported through `components/ui/index.ts` and used uniformly across all editor panels. The sibling `Dashboard.tsx` provides the non-editor view and navigation entry point into this editor via `/dashboard/editor/:id`.
