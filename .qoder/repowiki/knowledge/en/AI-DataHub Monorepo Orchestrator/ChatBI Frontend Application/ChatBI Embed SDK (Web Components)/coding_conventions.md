- Each public widget is a class extending `HTMLElement` that registers itself via `customElements.define` guarded by a `!customElements.get(...)` check, exposing configuration through `static get observedAttributes()` and reading values in `connectedCallback`/`attributeChangedCallback`.
- UI is rendered imperatively by setting `shadowRoot.innerHTML` with template literals, and user-supplied strings are always passed through a private `escapeHtml` helper before insertion to prevent XSS.
- Theming is centralized in `theme.ts`: components call `applyTheme(shadowRoot, theme)` which merges a `defaultTheme` with overrides and writes CSS custom properties prefixed with `--chatbi-*` onto `:host`, allowing host-page overrides via `document.documentElement` CSS variables.
- Network access goes exclusively through `ChatBIClient`, which encapsulates embed-token verification, scheduled refresh, 401 retry, and uniform error throwing; components never call `fetch` directly except for the SSE endpoint where the raw `Response` is returned to be streamed.
- External communication from components to host pages is done by dispatching `CustomEvent`s with `bubbles: true, composed: true` (e.g. `chatbi:ready`, `chatbi:message`, `chatbi:error`) so events cross the shadow boundary.
