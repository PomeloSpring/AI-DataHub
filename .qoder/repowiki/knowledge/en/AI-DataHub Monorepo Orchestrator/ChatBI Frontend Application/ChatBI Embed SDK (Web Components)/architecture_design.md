Single-package library built by Vite as a UMD module (`@chatbi/sdk`) whose entry `src/index.ts` re-exports two custom elements — `ChatBIChat` (a conversational data-analysis widget) and `ChatBIDashboard` (a dashboard browser/list viewer) — plus the shared `ChatBIClient` HTTP layer and theme utilities. Each component is an `HTMLElement` subclass that attaches an open Shadow DOM, reads configuration from attributes (`host`, `api-key`, `user-id`, `user-name`, `theme`, `height`, plus `dashboard-id`), applies a CSS-variable-driven theme via `applyTheme()`, injects inline base styles, and owns a single `ChatBIClient` instance for all API calls. The client handles embed-token lifecycle: initial `POST /api/embed/auth/verify`, scheduled refresh before expiry, automatic retry on 401, and a special `sendMessage` that returns a raw `Response` so the chat component can stream Server-Sent Events (`event:`/`data:` lines for `progress`, `token`, `thinking`, `done`, `error`). UI rendering is done via imperative `innerHTML` templates inside the shadow root; components emit `CustomEvent`s (`chatbi:ready`, `chatbi:message`, `chatbi:error`) bubbling out of the shadow boundary. Styles live in `src/styles/base.css` imported with Vite's `?inline` query so they are bundled into the UMD artifact alongside the JS.
