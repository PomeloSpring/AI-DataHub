- Entry: `main.tsx` mounts a React.StrictMode root with a global `TooltipProvider` (from shadcn/ui) and `Toaster` (sonner), then renders `App.tsx`.
- Routing: `App.tsx` defines all routes via `react-router-dom`'s `<Routes>`/`<Route>`, organized into three top-level layout modes — `/ws/:workspaceId/*` (WorkspaceLayout), `/data/*` (DataPlatformLayout), `/system/*` (SystemLayout) — plus full-screen pages (`/dashboard/editor`, `/screen`, `/report`). Legacy routes (`/chat`, `/history`, `/page`, `/admin`) are redirected through helper components that first load workspaces via `useWorkspaceStore` and then navigate to the new workspace-scoped paths.
- Layouts: `WorkspaceLayout`, `SystemLayout`, `DataPlatformLayout` provide sidebar navigation, theme/workspace switching, and nested `<Outlet>` rendering; they compose shared UI primitives from `@/components/ui`.
- State: Global app state lives in Zustand stores under `stores/` (`authStore`, `workspaceStore`, `themeStore`, `brandStore`, `dashboardStore`, `graphStore`, `pipelineStore`, `aiAssistantStore`, `chatStore`); stores persist token/user to `localStorage` and expose actions consumed by hooks.
- API layer: A single `axios` instance in `api/client.ts` is configured with a `/api` base URL, attaches Bearer tokens via request interceptor, and auto-refreshes on 401 using a subscriber queue. Feature-specific modules (`governance.ts`, `lineage.ts`, `metrics.ts`, `quality.ts`, `scheduledTask.ts`, `sync.ts`, `tags.ts`, `workspace.ts`) wrap endpoints per domain.
- Dev server: `vite.config.ts` sets up Vite + React, an `@` path alias to `src/`, and a comprehensive dev proxy mapping `/api/*` prefixes to seven backend microservices (authservice, datacatalog, datagov, dataviz, datamind, dataflow, aiplatform) with per-service timeouts for long-running chat/pipeline calls.
- Assets: `public/vite.svg` and `public/test/index.html` serve as static assets and test harness respectively.
