The module is split into three layers:
- Page entry `frontend/src/pages/Chat.tsx` renders the main chat UI: left sidebar for conversation CRUD, header with workspace/datasource/model/retrieval-strategy selectors, message list with streaming thinking/token rendering, chart/table/sql tabs via `ChartPicker`, an execution-details drawer, and an `@tool` mention dropdown for MCP tools in agent mode.
- State lives in two Zustand stores under `frontend/src/stores/`: `chatStore.ts` owns conversation/message lifecycle, SSE streaming over `/api/pipeline/send/stream` (with fallbacks to loop-engine and legacy endpoints), feedback/analysis/predict actions, and persistence via `saveMessages` PUT; `aiAssistantStore.ts` owns the floating assistant's own session, messages, and knowledge-base CRUD (`/ai-assistant/*`).
- Reusable sub-components live in `frontend/src/components/ai-assistant/` (`AIFloatingBox`, `ChatInterface`, `ConversationHistory`, `ContextPanel`, `KnowledgeManager`) and are re-exported from `index.ts`; they consume `useAIAssistantStore` independently of the main chat page.
Dependency direction is one-way: pages → stores → `api/client` (and raw `fetch` for SSE); components depend only on their store and shared UI primitives (`@/components/ui/*`).
