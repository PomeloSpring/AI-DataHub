Each child directory or file under `frontend/src/pages/admin/` is an independent admin page component (e.g. `WorkflowEditor.tsx`, `ScheduledTasks.tsx`, `IntegrationApps.tsx`, `ModelCenter.tsx`, `AuditLog.tsx`, `Roles.tsx`, `KnowledgeBase.tsx`) that mounts into the app's admin route tree; there is no shared parent container or cross-page state — inter-page communication happens via the global routing store rather than direct imports. The only internal sub-module with deeper structure is `workflow-editor/`, which encapsulates its own DAG canvas, node types, palette, config panel, and Zustand store (`store.ts`) isolated from the rest of the admin pages.
