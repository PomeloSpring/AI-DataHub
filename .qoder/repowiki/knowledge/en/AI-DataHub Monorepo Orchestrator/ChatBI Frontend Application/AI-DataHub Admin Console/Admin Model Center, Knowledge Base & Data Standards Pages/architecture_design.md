Each file is a self-contained React functional component mounted under `frontend/src/pages/admin/` and rendered by the app router.
- `ModelCenter.tsx` is a thin shell: it composes shadcn `Tabs`/`TabsContent` and delegates each tab to sibling pages (`../ModelLab`, `../ModelTrain`) or local sub-pages (`./WorkflowConfig`, `./PromptManager`, `../Admin` with an `embeddedTab` prop), so it owns no business logic.
- `KnowledgeBase.tsx` is a single-file feature page with internal state-driven tabs (`status | documents | upload | sync`). It calls the backend directly via a shared `../../api/client` axios instance on endpoints under `/ai-assistant/knowledge/*` (status, documents, debug, update, upload-multiple, delete, content). A simple regex-based Markdown renderer renders document content in a modal viewer.
- `Standards.tsx` is a paginated CRUD page for data governance standards. It uses the typed `governanceApi` from `@/api/governance` (with a `DataStandard` type) and reads the current workspace id from `useWorkspaceStore`. UI primitives come from `@/components/ui` (shadcn-style Button, Input, Dialog, Select, Switch, Badge) and feedback is shown via `sonner` toast.
Dependency direction is one-way: pages depend on shared API clients and UI primitives; they do not import each other.
