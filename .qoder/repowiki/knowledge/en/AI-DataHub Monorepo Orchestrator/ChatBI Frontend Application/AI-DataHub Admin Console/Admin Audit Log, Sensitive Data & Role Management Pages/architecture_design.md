Three independent React functional components (`AuditLog`, `SensitiveData`, `Roles`) under `frontend/src/pages/admin/`, each exporting a default component that renders a self-contained CRUD table plus dialogs. All three consume the backend exclusively through `@/api/governance` (`governanceApi.listAuditLogs`, `getSensitiveFields`, `create/update/deleteSensitiveField`, `scanSensitiveFields`, `listRoles`, `create/update/deleteRole`, `listPermissions`, `updatePermissions`). State is local to each page via `useState`/`useEffect`/`useCallback`; pagination uses client-side `page`/`size=20` with server-driven `total`. UI primitives come from a shared shadcn-style `@/components/ui/*` library (Button, Input, Badge, Select, Dialog, Switch), feedback via `sonner` toast, and icons from `lucide-react`. `SensitiveData` additionally reads the current workspace via `useWorkspaceStore` to scope API calls. There is no cross-page communication — each page owns its own data fetching, form state, and confirmation dialogs.
