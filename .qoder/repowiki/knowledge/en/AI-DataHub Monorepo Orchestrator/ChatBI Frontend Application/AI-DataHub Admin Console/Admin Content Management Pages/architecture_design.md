Each file is a self-contained React functional component mounted under `frontend/src/pages/admin/`, exposing a default export that renders a full-page admin view. The pages share a common UI layer built from shadcn/ui primitives (`Button`, `Dialog`, `Select`, `Tabs`, `Badge`, `Card`, `Table`) and `lucide-react` icons, with user feedback via `sonner` toasts. Data access is split by page: most pages use the shared `@/api/client` (an axios instance) — e.g. `PromptManager` calls `/admin/prompts*`, `ReportTemplates` calls `/report-templates*`, and `NotificationChannels` delegates to typed helpers in `@/api/scheduledTask`. `GraphEntities` bypasses the shared client and calls `/api/graph/*` directly via raw axios with a Bearer token read from `localStorage`. `DataManagement.tsx` acts as a tab shell that reuses existing `../Admin` and `../Playground` components via an `embeddedTab` prop rather than implementing its own CRUD. Each page owns its local state (lists, form objects, dialog visibility) and performs CRUD through async handlers that refresh lists on success.
