Four sibling React page components under `frontend/src/pages/admin/`, each a self-contained feature screen that fetches data via a shared HTTP client (`../../api/client` or `@/api/client`) and renders with shadcn/ui primitives. `IntegrationApps.tsx` is a full CRUD + key rotation + preview page for embed applications, persisting per-app API keys in `localStorage` under the `chatbi_app_keys` key and opening a test iframe at `/test/index.html`. `IntegrationLogs.tsx` is a read-only paginated table of embed usage logs with filters by app/user/status. `MCPAgentConfig.tsx` is a tabbed container (`Tabs` from shadcn) hosting three sub-views: `MCPServersTab` (CRUD for MCP server registrations with transport selection between `streamable_http` and `stdio`, tool discovery via `/admin/mcp-servers/{id}/test`, and JSON-based tools_config), `AgentsTab` (CRUD for agent definitions bound to an MCP server and datasource, with retry/iteration config serialized into a JSON `config` field), and `MCPMarket` (a separate file imported as a child). `MCPMarket.tsx` provides a browsable registry of MCP services with category filtering, npm package search/import via `/mcp-market/npm/search` and `/mcp-market/npm/import`, and install flows that collect required environment variables. All pages follow a consistent pattern: local state for loading/pagination/filtering, `useEffect`-driven data loads, toast feedback via `sonner`, and error handling that surfaces backend `detail` messages.
