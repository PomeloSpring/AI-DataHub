Three independent React functional page components (`Glossary.tsx`, `MetricsCenter.tsx`, `TagsManager.tsx`) mounted under the app's routing. Each component owns its full state lifecycle: local `useState` for lists, pagination, search/filter, dialog visibility, and in-flight flags; data fetching via `useEffect`/`useCallback` hooks calling a dedicated API client (`@/api/client` for terms, `@/api/metrics` for metrics, `@/api/tags` for tags) and normalizing responses into typed interfaces. Shared UI primitives come from `@/components/ui/*` (Button, Input, Badge, Dialog, Select), icons from `lucide-react`, and toast notifications from `sonner`. Cross-cutting context is read from `@/stores/workspaceStore` (via `useWorkspaceStore`) to scope requests by `currentWorkspaceId`. Dependency direction is one-way: pages → api clients → backend REST endpoints; no cross-imports between the three page files, keeping each domain self-contained.
