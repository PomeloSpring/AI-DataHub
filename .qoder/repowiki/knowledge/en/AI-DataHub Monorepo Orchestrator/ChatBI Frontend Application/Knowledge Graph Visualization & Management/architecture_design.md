Two-layer composition: `frontend/src/pages/KnowledgeGraph.tsx` is the page-level shell that owns routing state (`graphType`, `viewMode`), tab navigation (graph / metrics / dimensions / cypher), CRUD dialogs for metrics and dimensions, and Cypher query execution against `/api/graph`. It delegates the visual graph to `frontend/src/components/graph/KnowledgeGraph.tsx`, which wraps a `ReactFlowProvider` and renders a `KnowledgeGraphInner` component that transforms store-backed `graphData` into React Flow nodes/edges, applies Dagre layout via `utils/layout.ts` (TB for table/business graphs, LR for data-lineage), and exposes zoom/fit/re-layout toolbar actions. Node rendering is inlined as typed components (`TableNode`, `ColumnNode`, `TermNode`, `MetricNode`, `DimensionNode`, `DataSourceNode`, `ETLTaskNode`) registered through a `nodeTypes` map; edges use a single custom `KnowledgeEdge` with an `edgeColorMap` keyed by relation type (e.g. `HAS_COLUMN`, `JOIN`, `PRODUCES`). Cross-cutting state (selected node, fetch/search/sync/lineage queries) lives in `@/stores/graphStore`; the page subscribes via `useGraphStore` and passes callbacks (`onNodeSelect`, `onRefresh`) down to the view. The `edges/`, `nodes/`, `panels/`, `views/` subdirectories are reserved but currently empty, indicating a planned split-out of node/edge/panel implementations from the monolithic view file.
