Layered FastAPI application with a clear separation between HTTP routers (`api/`) and business logic (`services/`). `main.py` instantiates the FastAPI app, registers CORS, mounts each router under a prefixed path (e.g. `/api/admin/agents`, `/api/model-lab`, `/api/embed`), and exposes a `/health` probe. Each feature area has a paired `api/<feature>.py` defining Pydantic request models and route handlers that delegate to `services/<feature>_service.py`, which performs raw SQL via shared helpers `execute_query`, `execute_insert`, `execute_write` from `services.shared.common.db`. Routers are also re-exported through `api/__init__.py` for centralized discovery. The service depends on sibling packages: `services.shared.common` for DB access, `services.datamind.agent.router` for agent route reloading, and `backend/` (copied into the image) for additional utilities. Deployment is via Dockerfile (python:3.11-slim, installs both shared and service requirements, sets PYTHONPATH=/app) or via the shared `start.sh`/`stop.sh` scripts that manage PID files, logs, and port conflicts.
