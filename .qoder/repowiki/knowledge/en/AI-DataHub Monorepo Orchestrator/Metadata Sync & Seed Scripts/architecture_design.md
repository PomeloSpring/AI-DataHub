Flat collection of standalone CLI scripts under `sync/`, each runnable via `python -m sync.<script>` or `python <script>.py`. `metadata_sync.py` is the core: it reads datasource configs from `adh_datasources` (decrypting passwords on demand), connects to source systems (`pymysql` for MySQL/Doris `information_schema`, optional `elasticsearch` client for indices/aliases), computes incremental diffs against `adh.adh_table_info`, `adh_column_metadata`, and `adh_table_relations`, then writes back to the Doris metadata database using `DELETE+INSERT` idempotent upserts while preserving user-defined `business_desc`. Embeddings are generated via `backend.common.llm.embedding.generate_embedding` and stored as `ARRAY<FLOAT>` with HNSW ANN indexes. `rebuild_vectors.py` re-scans all `adh_*` tables and regenerates their embedding columns in batches of 50. `encrypt_passwords.py` is a one-shot migration that upgrades plaintext passwords in `adh_datasources`. `seed_mcp_market.py` upserts a curated list of MCP server entries into `adh.adh_mcp_registry`. `create_adh_tables.sql` defines the entire `adh` schema (tables, HNSW vector indexes, default system config rows). Dependency direction is one-way: scripts import shared helpers from `backend.common.*` (config, crypto, db, llm) but nothing in `backend` imports back into `sync/`.
