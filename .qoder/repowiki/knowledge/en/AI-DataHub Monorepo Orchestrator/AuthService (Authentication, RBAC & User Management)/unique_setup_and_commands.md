Built as a Docker image from `Dockerfile` (python:3.11-slim) that installs both `services/shared/common/requirements.txt` and this service's `requirements.txt`, sets `PYTHONPATH=/app`, exposes port 8006, and runs `uvicorn services.authservice.main:app --host 0.0.0.0 --port 8006`. Locally it can be started via `start.sh` or directly with `python -m uvicorn main:app` after adding the parent directory to `sys.path` (done automatically in `main.py`).
