Run locally with `./start.sh start` from the repo root (uses the shared `start.sh` which maps `dataviz` to `services.dataviz.main:app` on port 8004); stop with `./stop.sh` or `./start.sh stop`. Container image built via `Dockerfile` using `python -m uvicorn services.dataviz.main:app --host 0.0.0.0 --port 8004` and requires both `services/shared/common/requirements.txt` and `services/dataviz/requirements.txt` to be present at build time.
