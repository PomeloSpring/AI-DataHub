Organized as a flat package of reusable sub-packages under `services/shared/common/`, each exposing a stable interface consumed by sibling microservices:
- `config.py` is the single source of truth for environment-driven settings (metadata DB, vector DB, Redis, Langfuse, Anthropic, Qdrant, Neo4j, service/MCP ports) with backward-compatible aliases (`DORIS_*`, `CHATBI_*`).
- `cache/` defines an abstract `CacheBackend` in `base.py` with two concrete backends (`local.LocalCache`, `redis_cache.RedisCache`) selected via `factory.get_cache(prefix)` which falls back to local when Redis is unavailable.
- `vector/` defines an abstract `VectorStore` in `base.py` with implementations for Doris HNSW (`doris_store`), in-memory (`memory_store`), and Qdrant (`qdrant_store`); `hybrid_search` provides a default fallback.
- `llm/` wraps the Anthropic SDK behind `generate_sql`, `generate_sql_stream`, `generate_with_tools`, `generate_with_tools_stream` plus async wrappers; model config is loaded from the metadata API and cached per model id; all calls are instrumented with `langfuse.observe(as_type="generation")`.
- `db/` provides connection helpers: `metadata_db` connects to the central MySQL/Doris metadata store, `datasource_db` resolves external datasource configs and returns pymysql or Elasticsearch clients.
- `auth.py` implements JWT decode/validate FastAPI dependencies (`get_current_user`, `require_admin`), bcrypt password handling, user CRUD against `adh_users`, login lockout, audit logging, and AES-256-GCM encryption of sensitive fields via `crypto.py`.
- Top-level `utils.py`, `ttl_cache.py`, `embed_auth.py`, `mcp_base.py` hold extracted helpers (JSON sanitization, LLM JSON parsing, TTL cache decorator).
Dependency direction is one-way: sub-packages depend on `config.py` and `crypto.py`; they do not import each other except `cache.factory -> base + implementations` and `db.datasource_db -> db.metadata_db`. The package has no runtime entry point — it is imported as a library.
