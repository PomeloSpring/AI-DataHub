Configuration is loaded from `.env` files at `services/.env` (preferred) or `backend/.env` (fallback) via `python-dotenv`; runtime behavior is controlled entirely through environment variables such as `CACHE_BACKEND`, `METADATA_DB_*`, `VECTOR_DB_*`, `REDIS_URL`, `ANTHROPIC_API_KEY`, `QDRANT_*`, `LANGFUSE_*`. Optional features require extra packages: `elasticsearch` must be installed to use ES datasources, and Redis must be reachable for the `redis` cache backend (auto-falls back to local).
