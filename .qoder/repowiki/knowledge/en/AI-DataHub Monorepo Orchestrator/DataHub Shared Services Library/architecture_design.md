The `common/` package is the single source of cross-cutting infrastructure — configuration, auth, caching (local/Redis), vector stores (memory/Qdrant/Doris), LLM clients, and DB helpers — imported by every other subpackage. `graphservice` and `vectorservice` are independent FastAPI applications that each depend on `common/` plus the shared `models/` schemas, exposing REST endpoints backed by Neo4j and Doris respectively; they share an identical runtime layout via the top-level `Dockerfile.template`, which copies `shared/common/requirements.txt` first for cache efficiency and then installs per-service requirements before launching uvicorn. `mcp_client/` provides a transport-agnostic MCP client reused by services to call external tools, while `connectors/es_connector.py` and `migrations/*.sql` supply auxiliary data access and schema evolution used across the suite.
