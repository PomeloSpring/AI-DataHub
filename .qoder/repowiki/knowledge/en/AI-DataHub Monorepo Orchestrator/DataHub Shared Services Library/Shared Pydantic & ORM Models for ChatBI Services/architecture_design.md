The module is a flat collection of schema modules under `services/shared/models/` that serve as the single source of truth for API contracts consumed by multiple services. `schemas.py` is the largest file and groups Pydantic `BaseModel` classes by feature area using comment headers (Auth, Chat, Query, Dashboard, Admin, Playground, Datasource, Brand Settings, Menu Schemas, Component Data, Embed/Integration, Loop Engineering prompts/workflows/logs, Scheduled Tasks, Notification Channels, Report Templates). `ai_assistant.py` and `graph.py` are self-contained sub-packages each defining their own enums (`MessageRole`, `DocumentType`, `SyncStatus`; `GraphType`, `NodeType`, `RelationType`) plus request/response models for the AI Assistant and Knowledge Graph domains respectively. `menu_model.py` is the only SQLAlchemy ORM model in scope, declaring column metadata via a tuple constant and relying on raw SQL / `create_tables.sql` rather than migrations. There are no imports between these files — they are independent contract packages re-exported by consumers.
