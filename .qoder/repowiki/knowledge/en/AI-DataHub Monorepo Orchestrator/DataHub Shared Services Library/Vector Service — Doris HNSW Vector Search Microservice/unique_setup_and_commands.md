Run via `./start.sh {start|stop|restart|status}` which sources `services/.env`, launches Uvicorn with `PYTHONPATH=<project_root>`, and manages PID/log files under `<project_root>/pids` and `<project_root>/logs`. The Dockerfile installs both `services/shared/common/requirements.txt` and this service's `requirements.txt`, sets `PYTHONPATH=/app`, and starts via `uvicorn services.shared.vectorservice.main:app --host 0.0.0.0 --port 8010`. Environment variables `VECTOR_DB_HOST`, `VECTOR_DB_PORT`, `VECTOR_DB_USER`, `VECTOR_DB_PASSWORD`, `VECTOR_DB_DATABASE`, `VECTOR_DB_TYPE` are consumed from the shared config; the REST port defaults to 8010 (`VECTOR_SERVICE_PORT`) and the MCP SSE port is fixed at 31010.
