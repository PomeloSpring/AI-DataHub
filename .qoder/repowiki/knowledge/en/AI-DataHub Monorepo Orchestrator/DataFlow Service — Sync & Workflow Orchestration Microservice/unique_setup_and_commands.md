Run via `./start.sh {start|stop|restart|status}` which sources `services/.env`, launches uvicorn on port 8003 using the project's `venv/bin/python`, and logs to `logs/<service>.log` with PID tracking in `pids/`. For background jobs, start a Celery worker with `celery -A services.dataflow.tasks.celery_app worker -Q scheduled,default -l info -c 4` and a single Beat scheduler with `celery -A services.dataflow.tasks.celery_app beat -l info`; the Redis URL defaults to `redis://localhost:6379/0` and can be overridden by `REDIS_URL`. Environment variables include `AIRFLOW_API_URL`, `AIRFLOW_USERNAME`, `AIRFLOW_PASSWORD`, `AIRFLOW_DAGS_FOLDER`, `DATAFLOW_PORT`, and `LOG_LEVEL`.
