Flat Markdown-based documentation tree under `docs/` with a top-level `README.md` describing the intended layout (`api/`, `user-guide/`, `deployment/`, `development/`) and separating project docs from AI execution plans in `.claude/`. The `guides/` subdirectory contains feature-specific how-to pages (e.g., datasource configuration, scheduled tasks) written as step-by-step user manuals. Two standalone Markdown reports at the root document the knowledge-graph final design and implementation details. There is no build tooling or rendering pipeline — content is consumed directly as Markdown by consumers of the repository.
