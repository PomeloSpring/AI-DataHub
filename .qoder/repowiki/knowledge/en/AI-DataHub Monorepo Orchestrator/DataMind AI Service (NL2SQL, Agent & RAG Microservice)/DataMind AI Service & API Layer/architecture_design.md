Two-layer layout under `services/datamind/`: the `api/` subpackage defines FastAPI `APIRouter` modules (`chat.py`, `agent.py`, `knowledge.py`, `history.py`, `model_config.py`, `pipeline.py`, `playground.py`, `query.py`) that parse requests, enforce auth via `services.shared.common.auth.get_current_user`, and delegate to service classes in `services/`. The `services/` subpackage holds domain logic as single-purpose classes — `ChatService` (NL2SQL pipeline streaming via `execute_pipeline`), `AIAssistantService` (RAG + tool orchestration with `ai_assistant_tools`), `KnowledgeService` (document chunking, embedding, vector upsert), `ConversationService` (conversation persistence), and `GraphContextService` (Neo4j-backed knowledge-graph enrichment). Dependency direction is strictly `api → services → shared/nl2sql/rag/agent`; cross-service calls are lazy-imported inside methods (e.g. `from services.datamind.services.knowledge_service import KnowledgeService` inside route handlers) to avoid circular imports. Streaming responses use SSE (`text/event-stream`) for both chat and agent dispatch, while non-streaming routes collect the final `done` event from the orchestrator.
