Agent registration is lazy and triggered on first deep-mode request by querying `adh_agents` and registering each row as a `ConfigurableAgent`; datasource credentials are decrypted at runtime via `services.shared.common.crypto.decrypt_password`. The quick pipeline rejects non-query intents early using regex patterns, while deep/agent modes require an initialized event loop because they run the Loop Engine in a thread pool via `run_in_executor`.
