The module is organized around a pluggable strategy pattern plus shared retrieval primitives.

- Core retrievers in `rag_retriever.py` / `rag_retriever_v2.py` expose functions (`retrieve_table_info`, `retrieve_column_metadata`, `retrieve_sql_templates`, `retrieve_business_terms`, `retrieve_table_relations`, `retrieve_saved_datasets`, `retrieve_all`) that query Doris RAG tables (`adh_table_info`, `adh_column_metadata`, `adh_sql_templates`, `adh_business_terms`, `adh_table_relations`, `adh_saved_queries`) using either raw SQL with Doris HNSW `l2_distance_approximate` or a `VectorStore` abstraction for SQLite/others. A process-level LRU cache (`_RAG_CACHE`, max 128) and per-datasource caches for column metadata/BM25 indexes are used.
- `bm25.py` provides a pure-Python Okapi BM25 implementation plus an RRF fusion utility (`rrf_merge`) used to combine sparse (BM25) and dense (vector) rankings.
- `table_selector.py` performs keyword-based table selection; `terminology_manager.py` manages business terminology lookups.
- `strategies/` defines an abstract `RetrievalStrategy` interface (`base.py`) with a uniform return schema (`table_info`, `column_metadata`, `business_terms`, `table_relations`, `sql_templates`, `saved_datasets`, `rag_source`). Concrete strategies: `hybrid.py` (BM25+Vector RRF with sub-modes `full_table`, `two_stage`, `graph`), `graph.py` (NetworkX ego-graph traversal over a cached in-memory knowledge graph built from DB metadata), `bidirectional.py`, `column_first.py`, `full_table.py`, `two_stage.py` (legacy/complementary).
- `graph_rag/` is a sub-package providing Neo4j-backed persistence (`neo4j_store.py`, `async_neo4j_store.py`), a `GraphBuilder` to materialize the knowledge graph, and a `GraphRetriever` for graph-native queries; it is imported by the `graph` strategy but kept separate from the in-memory NetworkX path.
- Dependency direction: strategies depend on core retrievers and utilities; core retrievers do not import strategies. Vector store backends are selected at runtime via `VECTOR_DB_TYPE` config.
