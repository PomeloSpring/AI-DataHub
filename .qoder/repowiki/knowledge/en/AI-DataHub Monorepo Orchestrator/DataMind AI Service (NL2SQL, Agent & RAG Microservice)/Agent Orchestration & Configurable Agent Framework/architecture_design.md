Two cooperating sub-packages form the orchestration layer:

- `services/datamind/agent/` defines the runtime agent contract and dispatch. `base.py` declares the abstract `BaseAgent` (with `run`, `cancel`, `cleanup`, protection via `max_iterations`/`max_time_seconds`/`doom_loop_threshold`) and the `AgentResult` dataclass used by every agent. Concrete agents extend it: `sql_agent.py` wraps the existing NL2SQL quick/deep pipeline; `configurable_agent.py` is a generic DB-backed agent that loads system prompts, MCP server bindings, datasource bindings, and extra config from the `adh_agents` table and runs them through `agent_loop.AgentLoop`. `router.py` maintains a global `_agents` registry (`register_agent`/`get_agent`/`get_all_agents`) and implements two-stage routing: a fast regex path reading `route_patterns` from each agent's `skill.yaml` (via `config.agent_loader`), then an LLM-based classifier that lists active agents' descriptions and falls back to `sql_agent`. A singleton `AgentRouter` exposes `route()` and `execute()`, which also calls `agent.cleanup()` in a `finally` block.

- `services/datamind/config/` is the static configuration layer. `loader.py` loads skill/system prompt files under `skills/` and shared rules under `rules/` with filesystem-first semantics. `agent_loader.py` reads per-agent metadata from `config/agents/<name>/skill.yaml` and `system.md`, exposing helpers like `load_agent_skill`, `load_agent_prompt`, `get_max_retries`, `get_max_iterations`, `get_route_patterns`, `list_agent_dirs`, and `build_agent_graph`. Each agent directory pairs a `skill.yaml` (metadata, route patterns, input schema) with a `system.md` prompt. The `orchestrator/` subdirectory holds the main agent's `rules.md` and `skill.yaml`. `ai_assistant_config.py` is a separate env-driven settings module for the AI assistant knowledge base.

Dependency direction: `agent/*` depends on `config/*` for loading prompts/route patterns; `config/*` has no reverse dependency. Agents depend only on `base.BaseAgent`; the router is the single integration point between the outside world and concrete agents.
