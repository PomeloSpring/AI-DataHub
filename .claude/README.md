# .claude/ 目录说明

本目录用于存放 **AI Claude Code 的执行计划和任务跟踪**，与项目文档（docs/）分开管理。

## 📁 目录结构

```
.claude/
├── plans/              # 执行计划和技术设计
│   ├── ai-assistant-design.md    # AI助手技术设计
│   └── ...                       # 其他执行计划
├── tasks/              # 任务跟踪和TODO
│   ├── TODO-Optimization.md      # 优化事项跟踪
│   └── ...                       # 其他任务跟踪
└── README.md           # 本说明文件
```

## 📋 文档类型说明

### plans/ - 执行计划

存放AI Claude Code生成的：
- 技术设计方案
- 架构设计文档
- 实现方案文档
- 代码重构计划

**特点**：
- 由AI生成和维护
- 用于指导代码实现
- 包含详细的代码示例
- 随项目演进更新

### tasks/ - 任务跟踪

存放AI Claude Code管理的：
- TODO事项
- 优化任务跟踪
- 待讨论事项
- 进度记录

**特点**：
- 任务状态跟踪
- 优先级管理
- 决策记录
- 进度更新

## 🔗 与 docs/ 的区别

| 目录 | 内容 | 维护者 | 用途 |
|------|------|--------|------|
| `.claude/` | AI执行计划 | AI Claude Code | 指导代码实现 |
| `docs/` | 项目文档 | 开发团队 | 用户文档、API文档 |

## 📝 使用规范

1. **AI生成的文档** → 放在 `.claude/`
2. **项目官方文档** → 放在 `docs/`
3. **保持分离**：不要混放两种类型的文档
4. **及时清理**：完成的任务及时归档或删除
